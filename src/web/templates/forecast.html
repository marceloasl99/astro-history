📈 Previsão Probabilística v3 2026–2060

Cada ano recebe uma probabilidade com intervalo (p10–p90) comparada à taxa-base histórica, calculada por um modelo ajustado em bases objetivas (COW, NBER, UCDP/PRIO, catálogo v2) a partir de 409 features da astrologia mundana moderna (fases dos ciclos externos, Índice de Barbault, ativação de aspectos, harmônicos, declinação, eclipses…). O skill de cada modelo foi medido por hindcast walk-forward — e é mostrado antes de qualquer número.
